# SG5-Distance-Calculator-Program
## Description
This program converts the distance in kilometers to miles using arithmetic operators and and if-else structure.

## How to Run
1. Open the program file in VS Code, Programiz, Replit, or Google Colab.
2. Run the program.
3. Enter a value for the distance.
4. Check the distance displayed on the screen.

## Input Needed
- distance in kilometers

## Sample Output
Enter distance in kilometers: 67
Distance in miles: 41.631857000000004
Do you want to convert another distance? (yes/no): no
Program ended.
